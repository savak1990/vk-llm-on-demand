# CORE-060 Gateway (OpenAI-compatible API) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `internal/gateway` (the `/v1` OpenAI-compatible inference API) and the shared `internal/auth` key-loader package it depends on, so a real OpenAI SDK can complete plain and streamed chat calls against a READY worker, and gets a clean `backend_unavailable` otherwise.

**Architecture:** `internal/auth.Keys` loads and constant-time-classifies the three key files (client, management, worker-seed) from disk, reread every 10s. `internal/gateway.Gateway` wraps a narrow 5-method `Controller` interface (already implemented by `*internal/controller.Controller`, confirmed in code) with HTTP: a middleware chain (request-id, recover, body-limit, auth, rate-limit, logging-context) in front of two routes (`POST /v1/chat/completions`, `GET /v1/models`). Admission is one `Admit`/`RequestEnd` pair per request; the proxy reuses the `http.RoundTripper` the controller hands back from `Admit` — the gateway never dials or resolves an address itself.

**Tech Stack:** Go 1.26 stdlib (`net/http` method patterns, `crypto/subtle`, `crypto/sha256`, `log/slog`, `context`), `github.com/prometheus/client_golang/prometheus` (already an allowed dependency). No new third-party module.

**Spec:** `specs/core/060-P-gateway-openai-api/spec.md` (status DRAFT today; this plan carries it to DONE). Executors must read it in full alongside this plan — this plan does not restate every requirement, only the ones each task implements.

## Global Constraints

- `make specs-check`, `go-build`, `go-test`, `go-lint`, `helm-lint`, `helm-template` must all pass before the PR opens (CLAUDE.md "Validation"). Never claim a check passes without running it this session.
- No code comment may cite a spec/ADR number; explain WHY directly (CLAUDE.md "Code comments").
- Unit tests use fakes and the fake clock only — no sleeps, no real network beyond loopback `httptest` (spec R19, repo convention).
- `internal/gateway` MUST NOT call or reference `Start`, `Stop` or `Demand` on the controller (spec R8/AC11) — the `Controller` interface this package defines has exactly 5 methods.
- The 503 `backend_unavailable` body is a byte-exact literal from the spec (ADR 0010 §2): `{"error": {"type": "server_error", "code": "backend_unavailable", "message": "GPU backend is stopped; start it with ` + "`vk-llm start`" + `"}}` — never regenerate it through `encoding/json`, since that would not reproduce the verbatim spacing.
- Max hourly price / budget / instance-count invariants (CORE-050) are untouched by this plan — the gateway never starts, stops or dials anything.
- Consult the `advisor` tool once before starting implementation (done during planning) and again before declaring the work complete.
- Known deviations from the spec's literal text, to flag in the PR description (same convention as CORE-070's documented deviations), not hidden:
  1. The spec's package-surface sketch gives `gateway.New(cfg Config, ctl Controller, keys *auth.Keys, clk clock.Clock, reg prometheus.Registerer) (*Gateway, error)` (5 positional args, no logger). This plan instead uses `gateway.New(d Deps) (*Gateway, error)` with a `Deps` struct carrying `Controller`, `Keys`, `Clock`, `Config config.Gateway`, `InstallationID`, `Reg`, `Log *slog.Logger` — the same convention `internal/controller.New(d Deps)` and `internal/config.LoadController` already established in this repo. A positional 5-arg constructor would be the one inconsistent constructor in the codebase.
  2. The spec's design prose attributes the request-id/status-recorder/access-log middleware to `obs.RequestIDMiddleware`. `internal/obs` is still an empty one-line stub today (confirmed) and shaping a shared package two independent in-flight specs (this one and CORE-055) might consume differently is out of scope for this plan. This plan builds that middleware privately inside `internal/gateway`; a later observability spec (CORE-090) can extract it into `internal/obs` if `internal/mgmt` ends up needing the identical stack.
  3. The spec sketches `internal/auth` as this spec's own package, built here and consumed by CORE-055. In reality CORE-055 built it first (see below) — this plan vendors theirs rather than building a second, incompatible one. The spec's own prose fixes the worker-seed reload cadence at a literal "10s poll"; `internal/gateway`'s own `workerSeedReloadInterval` (Task 3) hardcodes that as an unexported constant rather than a configurable field nobody is meant to tune.
- Cross-session note: a parallel session is building CORE-055 (`internal/mgmt`) against the same `cmd/gpu-on-demand/main.go` scaffold. Task 16 below touches only the gateway's own half of that file (additive lines), to keep the eventual merge conflict small and mechanical.
- **`internal/auth` already exists, fully built, on the unmerged branch `core-055-management-api`** (17 commits ahead of `origin/main`, confirmed by reading the real files). This plan does NOT build a competing `internal/auth` package. The real, already-tested API (verbatim, read directly from that branch):
  ```go
  type Surface int // Inference, Management
  func Load(clientPath, mgmtPath string, c clock.Clock, log *slog.Logger) (*Keys, error)
  func (k *Keys) Check(authorization string, want Surface) (keyID string, err error) // ErrMissing, ErrMalformed, ErrUnknown, ErrWrongSurface
  func (k *Keys) Loaded() bool
  func (k *Keys) Run(ctx context.Context)
  func NewLimiter(rpm int, c clock.Clock) *Limiter
  func (l *Limiter) Allow(keyID string) (ok bool, retryAfter time.Duration)
  ```
  `Keys.Load` takes no worker-seed path — that package never touches the worker-signing seed at all. This plan's Task 2 temporarily vendors byte-identical copies of `internal/auth/keys.go` and `internal/auth/limiter.go` from `core-055-management-api` into this branch purely so `internal/gateway` has something real to compile and test against today, without blocking on their merge timing — the "temporary, delete at rebase" note lives in the commit message, not inside the vendored files, so this branch's copy stays byte-identical to theirs and a rebase sees a clean identical-content add rather than a conflict. **Delete both vendored files at the first rebase after `core-055-management-api` merges to `origin/main`** — do not modify them independently in the meantime; any gateway-side need that isn't met by the real API is handled in this package instead (see next point), never by editing the vendored copy.
  - Gateway needs the raw worker-seed bytes (32 bytes, for `worker.WorkerKey`), which `auth.Keys` never loads. This plan adds a small, fully independent loader, `internal/gateway/workerseed.go`, for that one file — no classification logic, no shared type with `internal/auth`, zero risk of colliding with CORE-055's package.
- Drain-cutoff detection compares `controller.Snapshot.State` against the internal `controller.Draining`/`controller.Destroying` enum values, never the `.Public` string — `PublicState(Destroying, failing=true)` returns `"FAILED"`, which a `"DRAINING"`/`"DELETING"` string compare would silently miss.
- Every SSE-shaped line (`data: {...}`) is legal only after this gateway has already written `w.WriteHeader(http.StatusOK)` with `Content-Type: text/event-stream` on the current response. Any failure that happens before that point — `Admit` returning an error, a transport error reaching the upstream, a non-2xx status received from the upstream — is always answered with a plain JSON status code, regardless of whether the client's request body said `"stream": true`. Only a failure that happens *after* the first chunk has already been flushed uses the in-stream `data: {"error":...}` + `data: [DONE]` form.
- `Gateway.Shutdown` and the SSE read loop use `g.deps.Clock`, never `time.Now`/`time.After`/`time.Sleep` directly, so both are testable with the fake clock. Tests in this package never call `time.Sleep`; they synchronize on a channel the test double closes.
- Prometheus collectors for `internal/gateway` are fields on `*Gateway`, created fresh in `New` and registered on `d.Reg` — never package-level `var` collectors — so two `Gateway` instances in two different tests never share state or double-register.

```go
// internal/config/gateway.go
package config

import (
	"time"
)

// Gateway configures internal/gateway's request limits and the model
// identity it reports; provisioning mode and the monthly budget cap
// live in Controller, not here.
type Gateway struct {
	ModelAlias         string
	MaxBodyBytes       int64
	MaxTokensCap       int
	RateLimitPerKeyRPM int
	GenerationTimeout  time.Duration
}

func LoadGateway() (Gateway, error) {
	var g Gateway
	var err error

	// Same default as config.LoadMgmt's own VKLLM_MODEL_ALIAS read
	// (CORE-055) — both loaders must agree on the unset case.
	g.ModelAlias = envString("VKLLM_MODEL_ALIAS", "qwen3.6-35b-a3b")

	maxBody, err := envInt("VKLLM_GATEWAY_MAX_BODY_BYTES", 1<<20)
	if err != nil {
		return Gateway{}, err
	}
	g.MaxBodyBytes = int64(maxBody)

	if g.MaxTokensCap, err = envInt("VKLLM_GATEWAY_MAX_TOKENS_CAP", 8192); err != nil {
		return Gateway{}, err
	}
	if g.RateLimitPerKeyRPM, err = envInt("VKLLM_GATEWAY_RATE_LIMIT_PER_KEY_RPM", 60); err != nil {
		return Gateway{}, err
	}
	if g.GenerationTimeout, err = envDuration("VKLLM_MODEL_GENERATION_TIMEOUT", 10*time.Minute); err != nil {
		return Gateway{}, err
	}
	return g, nil
}
```

```go
// internal/gateway/workerseed.go
package gateway

import (
	"context"
	"fmt"
	"os"
	"sync/atomic"
	"time"

	"github.com/savak1990/vk-llm-on-demand/internal/clock"
)

const workerSeedReloadInterval = 10 * time.Second

// WorkerSeed holds the worker-signing seed read from one file,
// independent of internal/auth (that package never loads this file).
// Exported because cmd/gpu-on-demand/main.go constructs one directly.
type WorkerSeed struct {
	path  string
	clk   clock.Clock
	bytes atomic.Pointer[[]byte]
}

func LoadWorkerSeed(path string, clk clock.Clock) (*WorkerSeed, error) {
	w := &WorkerSeed{path: path, clk: clk}
	if err := w.reload(); err != nil {
		return nil, err
	}
	return w, nil
}

// reload stores the file's bytes exactly as read — no trimming, no
// encoding conversion — so this side and the controller's own seed
// reader (CORE-050) always derive the same worker key from the same
// bytes.
func (w *WorkerSeed) reload() error {
	raw, err := os.ReadFile(w.path)
	if err != nil {
		return fmt.Errorf("gateway: worker seed: %w", err)
	}
	w.bytes.Store(&raw)
	return nil
}

func (w *WorkerSeed) Bytes() []byte {
	b := w.bytes.Load()
	if b == nil {
		return nil
	}
	return *b
}

func (w *WorkerSeed) Loaded() error {
	if len(w.Bytes()) != 32 {
		return fmt.Errorf("gateway: worker seed must be 32 bytes, got %d", len(w.Bytes()))
	}
	return nil
}

// Run reloads the seed file every workerSeedReloadInterval until ctx is
// done; a failed reload keeps serving the last good value.
func (w *WorkerSeed) Run(ctx context.Context) {
	if w.clk == nil {
		return
	}
	t := w.clk.NewTicker(workerSeedReloadInterval)
	defer t.Stop()
	for {
		select {
		case <-ctx.Done():
			return
		case <-t.C:
			_ = w.reload()
		}
	}
}
```

`LoadWorkerSeed(path, nil)` in `TestLoadWorkerSeed`/`TestLoadWorkerSeedRequires32Bytes`/`TestWorkerSeedBytesAreNeverTransformed` passes a nil `clock.Clock` deliberately — those tests never call `Run`, only `Loaded`/`Bytes`, so the nil check inside `Run` (not reached) is what keeps that safe.

```go
package gateway

import (
	"encoding/json"
	"net/http"
)

type errorBody struct {
	Error errorDetail `json:"error"`
}

type errorDetail struct {
	Message string `json:"message"`
	Type    string `json:"type"`
	Code    string `json:"code"`
}

func writeError(w http.ResponseWriter, status int, errType, code, message string) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(status)
	_ = json.NewEncoder(w).Encode(errorBody{Error: errorDetail{Message: message, Type: errType, Code: code}})
}

// backendUnavailableBody is byte-exact so an SDK's retry/exception logic
// sees identical bytes every time; json.Marshal would not reproduce this
// spacing.
const backendUnavailableBody = `{"error": {"type": "server_error", "code": "backend_unavailable", "message": "GPU backend is stopped; start it with ` + "`vk-llm start`" + `"}}`

func writeBackendUnavailable(w http.ResponseWriter) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(http.StatusServiceUnavailable)
	_, _ = w.Write([]byte(backendUnavailableBody))
}

func backendUnavailableSSE() string {
	return "data: " + backendUnavailableBody + "\n\ndata: [DONE]\n\n"
}
```

```go
// internal/gateway/gateway.go

// Package gateway serves the OpenAI-compatible inference API under /v1.
package gateway

import (
	"fmt"
	"log/slog"
	"net/http"
	"sync/atomic"
	"time"

	"github.com/prometheus/client_golang/prometheus"

	"github.com/savak1990/vk-llm-on-demand/internal/auth"
	"github.com/savak1990/vk-llm-on-demand/internal/clock"
	"github.com/savak1990/vk-llm-on-demand/internal/config"
	"github.com/savak1990/vk-llm-on-demand/internal/controller"
)

// Controller is the subset of *controller.Controller this package calls;
// Start, Stop and Demand are deliberately absent so the gateway cannot
// provision, stop, or register on-demand demand by construction.
type Controller interface {
	Admit(gen int64) (http.RoundTripper, error)
	RequestEnd(gen int64)
	ObserveFirstToken(gen int64, d time.Duration)
	ReportUpstreamFailure(gen int64)
	Status() controller.Snapshot
}

// Deps are every external dependency Gateway calls.
type Deps struct {
	Controller     Controller
	Keys           *auth.Keys
	Seed           *WorkerSeed
	Clock          clock.Clock
	Config         config.Gateway
	InstallationID string
	Reg            prometheus.Registerer
	Log            *slog.Logger
}

type Gateway struct {
	deps      Deps
	mux       *http.ServeMux
	startedAt time.Time

	// shuttingDown is read by Task 9's classify and set by Task 14's
	// Shutdown; declared here so Task 9 compiles before Shutdown exists.
	shuttingDown atomic.Bool
}

func New(d Deps) (*Gateway, error) {
	if d.Config.ModelAlias == "" {
		return nil, fmt.Errorf("gateway: model alias required")
	}
	if d.Controller == nil {
		return nil, fmt.Errorf("gateway: controller required")
	}
	if d.Keys == nil {
		return nil, fmt.Errorf("gateway: keys required")
	}
	if d.Seed == nil {
		return nil, fmt.Errorf("gateway: worker seed required")
	}
	if d.Clock == nil {
		d.Clock = clock.Real{}
	}
	if d.Log == nil {
		d.Log = slog.Default()
	}

	g := &Gateway{deps: d, startedAt: d.Clock.Now()}
	g.mux = http.NewServeMux()
	g.mux.HandleFunc("GET /v1/models", g.handleModels)
	return g, nil
}

// Handler returns the full /v1 handler; Task 5-7 extend this chain with
// auth, rate-limiting and the body-limit wrapper.
func (g *Gateway) Handler() http.Handler {
	return chain(g.mux,
		g.requestIDMiddleware,
		g.recoverMiddleware,
		g.loggingMiddleware,
	)
}

func chain(h http.Handler, mws ...func(http.Handler) http.Handler) http.Handler {
	for i := len(mws) - 1; i >= 0; i-- {
		h = mws[i](h)
	}
	return h
}
```

```go
// append to gateway.go

type ctxKey int

const ctxKeyRequestID ctxKey = iota

func newRequestID() string {
	var b [8]byte
	_, _ = rand.Read(b[:])
	return hex.EncodeToString(b[:])
}

func (g *Gateway) requestIDMiddleware(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		rid := newRequestID()
		w.Header().Set("X-Request-Id", rid)
		ctx := context.WithValue(r.Context(), ctxKeyRequestID, rid)
		next.ServeHTTP(w, r.WithContext(ctx))
	})
}

func (g *Gateway) recoverMiddleware(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		defer func() {
			if rec := recover(); rec != nil {
				g.deps.Log.Error("gateway: panic", "panic", true, "request_id", r.Context().Value(ctxKeyRequestID))
				// If headers already went out (e.g. a panic mid-stream,
				// after the 200/text-event-stream header was written),
				// writing a fresh status line is not legal HTTP — the
				// only safe thing left to do is stop, not write a 500.
				if sr, ok := w.(*statusRecorder); ok && sr.wroteHeader {
					return
				}
				writeError(w, http.StatusInternalServerError, "server_error", "internal_error", "internal error")
			}
		}()
		next.ServeHTTP(w, r)
	})
}

// statusRecorder wraps the response writer so the outermost middleware
// (Task 15's accessLogAndMetrics) can read the real status/outcome
// after a handler returns. codeOverride lets a handler record a metric
// label the plain numeric status cannot express (e.g. "499" written
// before any header, or "stream_error" for an in-stream failure that
// can't rewrite an already-sent 200) — both of those are legitimate
// cases Go's http package itself cannot represent as a second status
// code. Defined here (Task 4) rather than Task 15, even though metrics
// aren't wired yet, so Tasks 9-10's writePreHeaderOutcome/
// writeInStreamOutcome can call setCodeOverride from the start, instead
// of patching functions that exist in an earlier task.
type statusRecorder struct {
	http.ResponseWriter
	status      int
	wroteHeader bool
	codeOverride string
}

func (s *statusRecorder) WriteHeader(code int) {
	s.status = code
	s.wroteHeader = true
	s.ResponseWriter.WriteHeader(code)
}

// Unwrap lets http.ResponseController reach the underlying flusher
// through this wrapper, required for SSE flushing to keep working.
func (s *statusRecorder) Unwrap() http.ResponseWriter { return s.ResponseWriter }

// setCodeOverride is a no-op unless w is a *statusRecorder (it isn't,
// in any test that calls a handler directly without going through
// Handler()'s middleware chain — that's fine, those tests don't assert
// on metric labels).
func setCodeOverride(w http.ResponseWriter, code string) {
	if sr, ok := w.(*statusRecorder); ok {
		sr.codeOverride = code
	}
}

func (g *Gateway) loggingMiddleware(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		next.ServeHTTP(w, r)
	})
}
```

```go
// internal/gateway/middleware.go
package gateway

import (
	"context"
	"errors"
	"net/http"

	"github.com/savak1990/vk-llm-on-demand/internal/auth"
)

const ctxKeyKeyID ctxKey = iota + 100 // offset from ctxKeyRequestID, same int-key-type family

func (g *Gateway) authMiddleware(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		keyID, err := g.deps.Keys.Check(r.Header.Get("Authorization"), auth.Inference)
		switch {
		case err == nil:
			ctx := context.WithValue(r.Context(), ctxKeyKeyID, keyID)
			next.ServeHTTP(w, r.WithContext(ctx))
		case errors.Is(err, auth.ErrMissing):
			writeError(w, http.StatusUnauthorized, "authentication_error", "missing_api_key", "no api key provided")
		case errors.Is(err, auth.ErrMalformed):
			writeError(w, http.StatusUnauthorized, "authentication_error", "malformed_api_key", "authorization header must be a bearer token")
		case errors.Is(err, auth.ErrWrongSurface):
			writeError(w, http.StatusForbidden, "permission_error", "wrong_surface", "management tokens cannot call the inference api")
		default: // auth.ErrUnknown
			writeError(w, http.StatusUnauthorized, "authentication_error", "unknown_key", "the api key is not recognized")
		}
	})
}
```

```go
// clampMaxTokens returns the value to send upstream for max_tokens: cap
// if absent or over cap, the requested value otherwise. clamped is true
// whenever the value sent differs from what the client actually asked
// for (including "asked for nothing, got the cap").
func clampMaxTokens(body map[string]json.RawMessage, cap int) (clamped bool, value int, err error) {
	raw, ok := body["max_tokens"]
	if !ok {
		raw, ok = body["max_completion_tokens"]
	}
	if !ok {
		return true, cap, nil
	}
	var requested int
	if err := json.Unmarshal(raw, &requested); err != nil {
		return false, 0, errors.New("max_tokens must be an integer")
	}
	if requested > cap {
		return true, cap, nil
	}
	return false, requested, nil
}

func (g *Gateway) handleChatCompletions(w http.ResponseWriter, r *http.Request) {
	raw, err := io.ReadAll(r.Body)
	if err != nil {
		writeError(w, http.StatusRequestEntityTooLarge, "invalid_request_error", "request_too_large", "request body exceeds the size limit")
		return
	}

	var body map[string]json.RawMessage
	if err := json.Unmarshal(raw, &body); err != nil {
		writeError(w, http.StatusBadRequest, "invalid_request_error", "invalid_json", "request body is not valid json")
		return
	}

	var model string
	if raw, ok := body["model"]; ok {
		_ = json.Unmarshal(raw, &model)
	}
	if model != g.deps.Config.ModelAlias {
		writeError(w, http.StatusNotFound, "invalid_request_error", "model_not_found", "the requested model does not exist")
		return
	}

	stream := false
	if raw, ok := body["stream"]; ok {
		if err := json.Unmarshal(raw, &stream); err != nil {
			writeError(w, http.StatusBadRequest, "invalid_request_error", "invalid_request", "stream must be a boolean")
			return
		}
	}

	_, maxTokens, err := clampMaxTokens(body, g.deps.Config.MaxTokensCap)
	if err != nil {
		writeError(w, http.StatusBadRequest, "invalid_request_error", "invalid_request", err.Error())
		return
	}
	body["max_tokens"] = json.RawMessage(strconv.Itoa(maxTokens))
	delete(body, "max_completion_tokens")

	status := g.deps.Controller.Status()
	gen := status.Generation
	rt, err := g.deps.Controller.Admit(gen)
	switch {
	case errors.Is(err, controller.ErrBackendUnavailable), errors.Is(err, controller.ErrDraining):
```

```go
// copyUpstream2xx passes a confirmed 2xx plain response straight through.
func (g *Gateway) copyUpstream2xx(w http.ResponseWriter, resp *http.Response) {
	w.Header().Set("Content-Type", resp.Header.Get("Content-Type"))
	w.WriteHeader(resp.StatusCode)
	_, _ = io.Copy(w, resp.Body)
}

// copyUpstream4xx passes through a client-error body that already looks
// like this gateway's own {"error":...} shape unchanged; any other 4xx
// body is wrapped so the client still gets a parseable error.
func (g *Gateway) copyUpstream4xx(w http.ResponseWriter, resp *http.Response) {
	raw, _ := io.ReadAll(resp.Body)
	var probe errorBody
	if json.Unmarshal(raw, &probe) == nil && probe.Error.Message != "" {
		w.Header().Set("Content-Type", "application/json")
		w.WriteHeader(resp.StatusCode)
		_, _ = w.Write(raw)
		return
	}
	writeError(w, resp.StatusCode, "invalid_request_error", "upstream_rejected", "the worker rejected the request")
}

type upstreamOutcome int

const (
	outcomeClientGone upstreamOutcome = iota
	outcomeShuttingDown
	outcomeTimeout
	outcomeDrainCutoff
	outcomeUpstreamError
)

// classify decides why an upstream call failed, in priority order: a
// disconnected client first (nothing to report, nothing to write),
// then this gateway's own shutdown, then the per-request deadline,
// then a drain cutoff, and only then a genuine upstream failure worth
// reporting to the controller's suspect probe.
func (g *Gateway) classify(r *http.Request, err error) upstreamOutcome {
	if r.Context().Err() != nil {
		return outcomeClientGone
	}
	if g.shuttingDown.Load() {
		return outcomeShuttingDown
	}
	if errors.Is(err, context.DeadlineExceeded) {
		return outcomeTimeout
	}
	if g.isDrainCutoff() {
		return outcomeDrainCutoff
	}
	return outcomeUpstreamError
}

// isDrainCutoff reports whether the controller's internal state is
// Draining or Destroying — checked against the enum, never the Public
// string, because PublicState(Destroying, failing=true) reports
// "FAILED", which a "DRAINING"/"DELETING" string compare would miss.
func (g *Gateway) isDrainCutoff() bool {
	state := g.deps.Controller.Status().State
	return state == controller.Draining || state == controller.Destroying
}

// writePreHeaderOutcome writes a plain status for an outcome that
// happened before any response headers were sent to the client.
func (g *Gateway) writePreHeaderOutcome(w http.ResponseWriter, outcome upstreamOutcome) {
	switch outcome {
	case outcomeClientGone:
		w.WriteHeader(499)
	case outcomeShuttingDown:
		w.Header().Set("Retry-After", "30")
		writeError(w, http.StatusServiceUnavailable, "server_error", "shutting_down", "the server is shutting down")
	case outcomeTimeout:
		writeError(w, http.StatusGatewayTimeout, "server_error", "upstream_timeout", "the worker did not respond in time")
	case outcomeDrainCutoff:
		writeBackendUnavailable(w)
	default:
		writeError(w, http.StatusBadGateway, "server_error", "upstream_error", "failed to reach the worker")
	}
}

func inStreamError(code, message string) string {
	b, _ := json.Marshal(errorBody{Error: errorDetail{Message: message, Type: "server_error", Code: code}})
	return "data: " + string(b) + "\n\n"
```

```go
func (g *Gateway) streamUpstream(w http.ResponseWriter, resp *http.Response, gen int64, r *http.Request, start time.Time) {
	w.Header().Set("Content-Type", "text/event-stream")
	w.WriteHeader(http.StatusOK)
	rc := http.NewResponseController(w)

	firstByte := true
	buf := make([]byte, 32*1024)
	for {
		n, err := resp.Body.Read(buf)
		if n > 0 {
			if firstByte {
				g.deps.Controller.ObserveFirstToken(gen, g.deps.Clock.Now().Sub(start))
				firstByte = false
			}
			if _, werr := w.Write(buf[:n]); werr != nil {
				return
			}
			_ = rc.Flush()
		}
		if err != nil {
			if err != io.EOF {
				outcome := g.classify(r, err)
				if outcome == outcomeUpstreamError {
					g.deps.Controller.ReportUpstreamFailure(gen)
				}
				g.writeInStreamOutcome(w, rc, outcome)
			}
			return
		}
	}
}

// writeInStreamOutcome writes the in-stream error row for an outcome
// that happened after the 200/text-event-stream header already went
// out — the only place this gateway ever writes a "data: {...}" error.
// writeInStreamOutcome also calls setCodeOverride: headers (200,
// text/event-stream) already went out before this runs, so a second
// WriteHeader call would be silently ignored by net/http — the
// requests_total{code} label can only reflect "499"/"stream_error"
// through this override, never through rec.status.
func (g *Gateway) writeInStreamOutcome(w http.ResponseWriter, rc *http.ResponseController, outcome upstreamOutcome) {
	switch outcome {
	case outcomeClientGone:
		setCodeOverride(w, "499")
		return // nothing to write, the client is already gone
	case outcomeShuttingDown:
		setCodeOverride(w, "stream_error")
		_, _ = io.WriteString(w, inStreamError("shutting_down", "the server is shutting down")+"data: [DONE]\n\n")
	case outcomeTimeout:
		setCodeOverride(w, "stream_error")
		_, _ = io.WriteString(w, inStreamError("upstream_timeout", "the worker did not respond in time")+"data: [DONE]\n\n")
	case outcomeDrainCutoff:
		setCodeOverride(w, "stream_error")
		_, _ = io.WriteString(w, backendUnavailableSSE())
	default:
		setCodeOverride(w, "stream_error")
		_, _ = io.WriteString(w, inStreamError("upstream_error", "connection to the worker was lost")+"data: [DONE]\n\n")
	}
	_ = rc.Flush()
}
```

```go
// internal/gateway/gateway.go

// Gateway struct gains:
	activeWG  sync.WaitGroup
	activeMu  sync.Mutex
	activeFns map[int]context.CancelFunc
	nextID    int

// shutdownCutoffDelay returns how long to wait before cancelling active
// requests: ctx's deadline minus a 5s margin for handlers to write
// their own shutting_down response, floored at 0.
func shutdownCutoffDelay(now, deadline time.Time) time.Duration {
	d := deadline.Sub(now) - 5*time.Second
	if d < 0 {
		return 0
	}
	return d
}

// Shutdown stops accepting new activity, gives in-flight requests a
// cutoff window to write their own shutting_down response, then cancels
// whatever is still running and waits for every handler to return; the
// instance itself is never touched — only HTTP serving stops.
func (g *Gateway) Shutdown(ctx context.Context) error {
	g.shuttingDown.Store(true)
	if deadline, ok := ctx.Deadline(); ok {
		if delay := shutdownCutoffDelay(g.deps.Clock.Now(), deadline); delay > 0 {
			select {
			case <-g.deps.Clock.After(delay):
			case <-ctx.Done():
			}
		}
	}
	g.cancelActive()

	done := make(chan struct{})
	go func() { g.activeWG.Wait(); close(done) }()
	select {
	case <-done:
	case <-ctx.Done():
	}
	return nil
}

func (g *Gateway) registerActive(cancel context.CancelFunc) (id int) {
	g.activeMu.Lock()
	defer g.activeMu.Unlock()
	id = g.nextID
	g.nextID++
	g.activeFns[id] = cancel
	return id
}

func (g *Gateway) unregisterActive(id int) {
	g.activeMu.Lock()
	defer g.activeMu.Unlock()
	delete(g.activeFns, id)
}

func (g *Gateway) cancelActive() {
	g.activeMu.Lock()
	defer g.activeMu.Unlock()
	for _, cancel := range g.activeFns {
		cancel()
	}
}
```

```go
func (g *Gateway) streamUpstream(w http.ResponseWriter, resp *http.Response, gen int64, r *http.Request, start time.Time) {
	w.Header().Set("Content-Type", "text/event-stream")
	w.WriteHeader(http.StatusOK)
	rc := http.NewResponseController(w)

	firstByte := true
	chunks := 0
	buf := make([]byte, 32*1024)
	for {
		n, err := resp.Body.Read(buf)
		if n > 0 {
			if firstByte {
				ttft := g.deps.Clock.Now().Sub(start)
				g.deps.Controller.ObserveFirstToken(gen, ttft)
				g.metrics.ttftSeconds.Observe(ttft.Seconds())
				firstByte = false
			}
			chunks += bytes.Count(buf[:n], []byte("data: "))
			if _, werr := w.Write(buf[:n]); werr != nil {
				return
			}
			_ = rc.Flush()
		}
		if err != nil {
			if err == io.EOF {
				if elapsed := g.deps.Clock.Now().Sub(start).Seconds(); elapsed > 0 && chunks > 1 {
					g.metrics.outputTokensPerSecond.Observe(float64(chunks-1) / elapsed) // -1 for the final [DONE] row
				}
			} else {
				outcome := g.classify(r, err)
				if outcome == outcomeUpstreamError {
					g.deps.Controller.ReportUpstreamFailure(gen)
				}
				g.writeInStreamOutcome(w, rc, outcome)
			}
			return
		}
	}
}
```
